# Real Room schema exports (FR-13 / risk R5)

Every `.json` file below is a Room exported schema copied **byte-for-byte unmodified** from a public
repository. Layout: `<source>/<database folder as in the source repo>/<version>.json` — the folder name
is passed to the parser as the database name, exactly as the plugin does for `schemas/<db class>/`.

All source repositories are licensed **Apache-2.0** (checked via the GitHub repository licence metadata
on 2026-11-17), which permits redistribution; the files are reproduced here under that licence,
copyright their respective authors (The Android Open Source Project; Google LLC; DuckDuckGo;
Home Assistant / Open Home Foundation).

Tests: `RealSchemaFixturesTest` (precise per-shape assertions) and `RealSchemaSweepTest` (every file here
parses and the model matches an independent read of the raw JSON; see `RealSchemaConsistency`).

"Era" is inferred from the file's shape (e.g. `views` appeared in Room 2.1, index `orders` in 2.5,
omitted `notNull` for nullable columns in 2.6+/KSP), not from commit history.
